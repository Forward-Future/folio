# Printing

Choose **More → Print** or press **Ctrl+P** (**⌘P** on macOS).

## Basic

The desktop app opens to **Basic**. The preview starts on the current page and follows each page’s dimensions and rotation as you browse. **Print…** opens the system print dialog with the full PDF, including current annotations and page order. Choose the printer, pages, and copies there. Printing preserves the document’s unsaved marker.

The browser edition uses the browser’s PDF print dialog.

## Advanced

Choose **Advanced** to lay out sheets before opening the system print dialog.

- **Single page** fits, shrinks, or scales pages. Actual size and custom scale can clip content at the quarter-inch margins.
- **Poster** tiles enlarged pages from left to right, then top to bottom. Set the scale and overlap in inches or millimeters. The default overlap is 0.25 inches (6.35 mm). Trim the margins and align the repeated content.
- **Pages per sheet** places 2, 4, 6, 9, or 16 pages on each sheet.
- **Booklet** pairs pages for folding and pads the last sheet where necessary. For eight pages the sides are 8/1, 2/7, 6/3, and 4/5. Use a duplex printer and select two-sided printing with short-edge binding for landscape or long-edge binding for portrait.

**Paper and quality** offers Letter, A4, or Legal, output at 150, 300, or 600 dpi, and grayscale or lighter ink. Automatic orientation follows each source page for Single page and Poster. Pages per sheet and Booklet default to landscape. Advanced jobs use one paper size. Folio turns differently oriented sheets to fit the printer’s job orientation.

Advanced layouts render sheets as images. Limits are 100 sheets, 48 megapixels per sheet, 576 MiB of decoded sheet pixels, and 64 MiB of encoded data per job. If a job exceeds a limit, reduce the resolution, select fewer pages, or use Basic to print the PDF directly.

**Continue to print…** opens the system dialog for confirmation. Keep the selected paper size and 100% scaling to preserve the previewed layout. Printer properties and tray selection depend on the driver.
